# Django Backend Engineering Standards — Index

**Purpose:** These standards define how AI coding agents should plan, implement, test, review, and maintain a Django backend. Follow them for every feature, from the first endpoint through production deployment.

**Core principle:** Plan globally, design each feature before implementing it, build incrementally, and test continuously.
